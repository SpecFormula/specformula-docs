## Shared contract

Regardless of language, plugins use the same configuration and contribution names:

- plugin id: maps to `isa.yml plugins.config.<id>`.
- `instructions`: provides new `instruction_type` values.
- `lifecycle_hooks`: provides hooks around test execution.
- `spec_readers`: provides readers for additional spec kinds.
- `disabled.instructions` / `disabled.lifecycle_hooks` / `disabled.spec_readers`: lets users disable individual contributions from `isa.yml`.

For implementation details, open the language-specific page.
