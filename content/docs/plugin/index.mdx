## 共通契約

無論哪個語言，Plugin 都圍繞同一組配置與 contribution 名稱：

- plugin id：對應 `isa.yml plugins.config.<id>`。
- `instructions`：提供新的 `instruction_type`。
- `lifecycle_hooks`：提供可在測試執行前後觸發的 hook。
- `spec_readers`：提供額外 spec kind 的 reader。
- `disabled.instructions` / `disabled.lifecycle_hooks` / `disabled.spec_readers`：使用者可在 `isa.yml` 停用個別 contribution。
